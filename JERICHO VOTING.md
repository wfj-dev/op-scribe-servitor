JERICHO VOTING 7/21/2026

1. Who votes:
Anyone on the current roster is eligible to vote.

2. Quorum:
60% of the active roster must vote (yes, no, or abstain) for the vote to count. If we don’t reach 60%, we revote.

3. Passing:
66% of the yes + no votes must be yes to pass. Abstentions count toward quorum but not the final percentage.

4. Automatic revote:
We revote if:

• The result is too close to the 66% passing mark.
• 35%+ of voters abstain.

5. Recusal:
If the vote is about you, you don’t vote and are removed from the roster count for that vote so you don’t affect quorum.

6. High Command positions:
Votes for High Command seats would have a higher passing requirement than normal WatchCom promotions. Quorum stays the same, but the passing threshold would be higher — thinking around 75%.

The bot would handle all the calculations automatically based on the current roster size.
