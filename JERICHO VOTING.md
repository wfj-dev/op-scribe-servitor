JERICHO VOTING 9/8/2026

1. Who votes:
Anyone on the current roster is eligible to vote.

2. Quorum:
60% of the active roster must vote (yes or no) for the vote to count. If we don't reach 60%, we revote.

3. Passing:
80% of the yes + no votes must be yes to pass. There is no abstain option — not voting simply counts against quorum.

4. Automatic revote:
We revote if:

• The result is too close to the 80% passing mark.
• Quorum (60%) is not met.

5. Recusal:
If the vote is about you, you don't vote and are removed from the roster count for that vote so you don't affect quorum.

6. High Command positions:
Same 80% passing threshold and quorum apply to High Command seats as any other WatchCom promotion — there is no separate threshold tier.

The bot handles all the calculations automatically based on the current roster size.
